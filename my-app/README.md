# Eventos Escolares Frontend

Aplicación web construida con SvelteKit y Vite.

## Requisitos

- Node.js y npm
- El backend de Eventos Escolares disponible en la URL configurada en `VITE_API_URL`

## Configuración

```powershell
npm install
Copy-Item .env.example .env
```

Si el backend usa otra dirección, cambia `VITE_API_URL` en `.env`.

## Desarrollo

```powershell
npm run dev
```

## Compilación

```powershell
npm run build
npm run preview
```
